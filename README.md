# SupCenter

SupCenter — локальный прототип системы обратной связи сотрудников для хакатона ГК «Модус Трейд». Он помогает принять обращение, назначить ответственного, сообщить автору результат и опубликовать полезное изменение для всей компании.

| Демо-профиль | Что можно сделать |
| --- | --- |
| Сотрудник | Подать именное или анонимное обращение, уточнить детали в чате, проследить за статусом и оценить решение. |
| Координатор | Разобрать входящие, выставить приоритет, назначить исполнителя и срок, обработать спам, объединить повторы, управлять профилями и публиковать итоги. |
| Исполнитель | Посмотреть назначенные обращения, запросить уточнение и зафиксировать результат. |

## Локальный запуск

1. Установите **Node.js 22.13 или новее** с npm.
2. Откройте терминал в корне проекта и выполните:

   ```powershell
   npm ci
   node server.js
   ```

3. Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000), выберите демо-профиль и нажмите **«Подтвердите вход»**. Для остановки сервера нажмите `Ctrl+C`.

При первом запуске сервер копирует `demo/jury.sqlite` в рабочую базу `feedback.sqlite`. Снимок включает обращения, вложения, оценки и публикации. Если рабочая база уже существует, сервер использует её. Если снимка нет, пустая база заполняется тестовыми обращениями из `seed.json`. Локальные изменения сохраняются в SQLite на компьютере, где запущен сервер.

Основные сценарии работают без настройки интеграций. Для Gemini и Telegram понадобится локальный `.env`.

Шаги инструкции зависят от роли и страницы. Интерфейс доступен на русском, казахском и английском.

1. **Подача.** Войдите как сотрудник и создайте обращение. Выберите тип и способ отправки. В форме и чате можно прикрепить до трёх фото или видео общим размером до 12 МБ. Микрофон записывает до минуты, а Gemini преобразует запись в редактируемый текст при настроенном ключе и разрешении браузера.
2. **Обработка.** Перейдите в профиль координатора, найдите обращение по номеру и нажмите **«Поручить»**. Укажите исполнителя, срок и задачу. При подключённом Gemini кнопка **«Рекомендация ИИ»** предложит черновик ответа, поручение и исполнителя. Координатор проверяет предложение перед использованием.
3. **Решение.** Войдите под назначенным исполнителем, откройте **«Назначенные мне»** и зафиксируйте итог через **«Изменить статус»**. Если сначала требуется уточнение, задайте вопрос через статус **«Ожидает уточнения»**. Автор увидит результат в своём чате и сможет оценить выполненное решение.
4. **Повторы и лента.** Координатор может объединить похожие открытые жалобы и назначить одного исполнителя. Итог общего дела появляется в отдельных чатах авторов. В **«Ленте»** координатор публикует обезличенный итог завершённых обращений, а сотрудники ставят от 1 до 5 звёзд и оставляют комментарии. В карточке **«Мои обращения»** виден статус последнего обращения и доступен переход в чат.
5. **Аналитика.** Нажмите сектор 3D-диаграммы или строку статуса, чтобы раскрыть список обращений, увидеть просрочки и открыть переписку. Здесь же доступны оценки компании и решений с комментариями и выгрузка сводки в PDF.

Раздел **«Работники»** позволяет координатору добавлять, редактировать и удалять демо-профили с сохранением истории обращений. Раздел **«Спам и нарушения»** позволяет ответить автору, вернуть обращение или удалить чат.

## Настройка интеграций

В PowerShell создайте локальный файл настроек, если его ещё нет:

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

Внесите нужные значения и перезапустите сервер. Git игнорирует `.env` и рабочую базу.

| Переменная | Назначение |
| --- | --- |
| `GEMINI_API_KEY` | Ключ для рекомендаций, расшифровки голоса, поиска похожих проблем и дополнительной модерации. |
| `GEMINI_MODEL`, `GEMINI_AUDIO_MODEL` | Модели для текстовых задач и расшифровки аудио. Значения по умолчанию указаны в `.env.example`. |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` | Токен бота и имя пользователя бота без `@`. |
| `TELEGRAM_CHAT_ID` | Необязательный ID чата владельца для журнала действий. |

**База ответов.** Координатор может сохранить своё сообщение как общий ответ. При настроенном Gemini утверждённый ответ может автоматически появиться в чате нового обращения типа «Вопрос», если вопрос совпадает по смыслу.

**Telegram.** В кабинете координатора нажмите **«Подключить уведомления»**, перейдите к боту и нажмите **«Старт»**. Ссылка действует пять минут. Подписка на этом экземпляре сайта действует до восьми часов или до перезапуска сервера. Подписчикам приходит полный текст новых обращений. Журнал действий отправляется в отдельно настроенный чат владельца. Для одного бота запускайте один экземпляр сервера.

## Структура проекта

| Файл или папка | Назначение |
| --- | --- |
| `server.js` | HTTP-сервер, API, демо-сессии, проверка прав и операции с SQLite. |
| `public/index.html`, `public/style.css`, `public/app.js` | Страницы, оформление, чаты, профили и пошаговые инструкции. |
| `public/analytics.js`, `public/repeats.js`, `public/improvements.js` | Аналитика и PDF, повторяющиеся проблемы и лента. |
| `public/media-input.js`, `attachments.js` | Запись голоса, загрузка и выдача вложений. |
| `public/i18n.js`, `public/translations.txt` | Языки интерфейса. |
| `integrations.js`, `telegram-links.js` | Вызовы Gemini и Telegram, подключение и доставка уведомлений. |
| `moderation.js`, `repeats.js` | Проверка сообщений и поиск повторяющихся проблем. |
| `demo/jury.sqlite`, `seed.json` | Снимок данных для жюри и резервный набор тестовых обращений. |
| `.env.example`, `public/supcenter-promo.mp4` | Шаблон настроек и ролик для кнопки «Подробнее о сервисе». |

SupCenter слушает `127.0.0.1` и использует демо-профили без паролей. Для работы с реальными данными сотрудников понадобится корпоративная аутентификация.
